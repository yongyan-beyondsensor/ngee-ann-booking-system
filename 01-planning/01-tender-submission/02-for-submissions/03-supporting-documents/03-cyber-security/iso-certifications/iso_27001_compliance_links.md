# ISO/IEC 27001 & Compliance Resources

This document provides direct links, compliance statuses, and instructions for accessing security attestations and certifications for Resend, Supabase, and Vercel.

---

## 1. Resend

- **ISO 27001 Status:** **Not Certified**
  - Resend focuses on SOC 2 Type II compliance and does not currently maintain an ISO/IEC 27001 certificate.
- **Available Attestations:** SOC 2 Type II, Data Processing Addendum (DPA), HIPAA (Enterprise).
- **Links & Access:**
  - [Resend Security Portal](https://resend.com/security) – Overview of security controls, infrastructure, and policies.
  - [Resend Support / Inquiries](https://resend.com/support) – Submit a request to the security team if custom vendor assessment questionnaires or non-disclosure SOC 2 reports are required.

---

## 2. Supabase

- **ISO 27001 Status:** **Certified** (ISO/IEC 27001:2022)
- **Download Access Requirements:** Available for **Team** and **Enterprise** plans, or upon request via the Trust Center.
- **Links & Access:**
  - [Supabase Trust Center](https://trust.supabase.io/) – Public security repository to request certifications, penetration testing reports, and compliance frameworks.
  - [Supabase Security Overview](https://supabase.com/security) – Detailed infrastructure security, shared responsibility model, and encryption standards.
- **Direct In-Dashboard Download:**
  1. Navigate to the [Supabase Dashboard](https://supabase.com/dashboard).
  2. Select your Organization.
  3. Go to **Organization Settings** > **Legal Documents** (or **Compliance**).
  4. Download the current ISO 27001 Certificate PDF.

---

## 3. Vercel

- **ISO 27001 Status:** **Certified** (ISO/IEC 27001:2022)
- **Download Access Requirements:** Publicly requestable via the Trust Center, or immediately downloadable for **Pro** and **Enterprise** teams.
- **Links & Access:**
  - [Vercel Trust Center](https://security.vercel.com/) – Filter by "ISO/IEC 27001" to review controls and request the complete audit certificate package.
  - [Vercel Security & Compliance Documentation](https://vercel.com/docs/security/compliance) – Reference guide on compliance standards (ISO 27001, SOC 2 Type 2, PCI DSS).
- **Direct In-Dashboard Download:**
  1. Navigate to the [Vercel Dashboard](https://vercel.com).
  2. Select your Team.
  3. Go to **Settings** > **Security** > **Attestations & Compliance**.
  4. Download the ISO/IEC 27001 Certificate.
